For managers · JEV

Decide first.
Write second.

JEV (from TypeSafe) helps Ask Vidura and AI quizzes stay on topic, cover the full book, and spend less on AI. Moodle still holds grades.

October 2026 · Sheet item: JEV + lower AI cost

Why we need it

Four problems we keep seeing.

CostEvery long AI chat and quiz costs money — both the question we send and the answer we get.
FocusStudents can ask things outside the class. The coach must answer only from approved lessons.
CoverageAI quizzes must use the whole book, not only the first chapters.
TrustTeachers need to see what the AI decided. We save that in learning records (xAPI) — not a black box.

Two jobs — easy to remember

🎯 JEV

The boss: Is this on topic? How should we teach? Cheap AI or full AI? Did the quiz cover everything?

&
✍️ Chat AI

The writer: Writes the answer or quiz questions — only when JEV says yes.

JEV replies in a split second with a short yes/no style answer. Students never see that message.

What JEV is not

Clear limits — so nobody expects the wrong thing.

Not another school chatbot or campus help widget
Not Moodle — students and grades still live there
Not the thing that marks work or sends scores back
Not needed for demos — EdVidura still works if JEV is off
Not a new content team — it only guides the AI before it writes

Where it sits

What happens in Ask Vidura

Load the approved class lessons
Ask JEV — on topic? how to teach? cheap or full AI?
Off topic → polite “please stay on class” — no AI cost
Easy path → short local answer
Full AI → longer answer with lesson citations, saved to learning records

AI quizzes (matches the sheet)

Three difficulty levels · whole-book coverage · checks the study plan.

Teacher sets options

Level, how hard, and how much of the book to cover — before making questions.

Make questions

AI or local path builds a quiz for each student.

JEV checks

Do the questions cover all the section titles?

Fix gaps

If coverage is weak → auto second pass adds questions across the missing units.

Money story (simple)

JEV decision (tiny call)~1×
Full AI answer (when we skip it)~100–400×

After we turn it on, we can count how often JEV saved a full AI call (jev_skipped_remote in our learning records).

How we turn it on

Get the TypeSafe API key
Set on Railway: JEV_ENABLED=1 and the key
Check AI status shows JEV is ready
Try on Riverside — coach chat + quiz
Adjust the confidence setting after teachers review
