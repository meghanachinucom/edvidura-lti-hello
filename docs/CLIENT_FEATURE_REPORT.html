EdVidura · Client briefing

What’s ready for classroom demos

A clear walkthrough of the learner and teacher experience after the latest CampusHub UI polish, plus the learning features already wired behind it. Moodle remains the gradebook of record.

Production app App edvidura-app on Railway Branch feature/slice-a-quiz Date 3 Nov 2026

1. Clearer screens for demos

Screens were simplified so clients can understand them at a glance — same jobs, less clutter.

  • Student home — calm dashboard with one job per section and breathing room.
  • My Progress — roadmap, skills, gaps, and goals with short copy and simple cards.
  • Ask Vidura — handbook-backed hints; fewer toolbar buttons; clearer “no quiz answers” stance.
  • Lessons & manuals — one primary action; shorter heroes; offline handbooks easy to open.
  • Quiz & XR labs — focused checkpoint flow; simpler lab cards to launch.
  • Teacher results — class mean, sync to Moodle, filters without a crowded hero.
  • Teacher diagnostics — Stuck / Activity / xAPI / Gaps tabs with plain language and room to scan.

2. For learners

What a student can do in the course tool launched from Moodle.

  • Continue the next lesson or lab
  • Take Checkpoint quizzes with instant feedback
  • Ask Vidura for Socratic help from approved sources
  • Read class manuals / PeBL handbooks (incl. offline-friendly reader)
  • See progress, skill levels, and suggested next steps
  • Open spatial / WebXR practice labs where enabled

3. For teachers

Section-scoped — not a district SIS replacement.

  • Review class results and sync grades to Moodle (LTI AGS)
  • See where the class is stuck and assign short drills
  • Inspect activity heatmaps and xAPI statements
  • Map competencies / close skill gaps (Difference training)
  • Authoring helpers: DCT planner, SME sources, CAT mapping

4. Platform capabilities (behind the UI)

Already in the product architecture for school / corporate / government tenants.

  • LTI 1.3 Advantage — launch from Moodle; Dynamic Registration onboarding; grade passback.
  • Tenant isolation — each school or org is separated at the database (RLS).
  • Adaptive / Difference paths — gap analysis and personalised next activities.
  • SME / handbook index — approved manuals feed the study coach; public query + ETIMS webhook for content sync.
  • Competency (CAT) — TO → skill mapping and evidence-linked proficiency levels.
  • xAPI middleware — statements for labs, quizzes, and diagnostics.
  • Multi-language UI — Indian language catalog for key handbook surfaces.
  • Government packs — Pravachana video library path (segment-specific).

5. What stays in Moodle

Important for client trust and procurement conversations.

  • Official gradebook and enrolment remain in the LMS.
  • EdVidura is the practice, coaching, and diagnostics layer inside the course.
  • Scores and sync status are visible in teacher results before / after Moodle passback.

6. Suggested client walkthrough (10–12 min)

  • 1 min — Open student home; show calm layout and “continue lab”.
  • 2 min — Lessons → open a lab; then Checkpoint quiz (submit stays official in Moodle).
  • 2 min — Ask Vidura a slope/intercept question; point at handbook citations.
  • 2 min — Manuals → open handbook reader.
  • 2 min — My Progress → Roadmap / Skills / Gaps.
  • 3 min — Switch to teacher → Results (sync) → Diagnostics (Stuck + Gaps).
